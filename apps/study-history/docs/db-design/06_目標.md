# 目標（`goals`）

ユーザーが設定する目標時間。

## カラム

| カラム名 | 型 | NULL | 既定値 | 説明 |
|---|---|---|---|---|
| `id` | number (auto-increment) | NO | 自動 | 主キー |
| `target_minutes` | number | NO | — | 目標時間（分）。UI では時間単位で入力し、分に変換して保存 |
| `period` | string | NO | — | 目標の期間種別。`'daily'` / `'weekly'` / `'monthly'` のいずれか |
| `category_id` | number | YES | null | 特定カテゴリに対する目標の場合に設定。null なら全体目標 |
| `is_active` | boolean | NO | true | 有効／無効フラグ |
| `created_at` | number (epoch ms) | NO | 自動 | レコード作成時刻 |
| `updated_at` | number (epoch ms) | NO | 自動 | レコード最終更新時刻 |

## インデックス

| 名称 | カラム | 用途 |
|---|---|---|
| `idx_period` | `period` | 期間種別ごとの目標取得 |
| `idx_category_id` | `category_id` | カテゴリ別目標の取得 |
| `idx_is_active` | `is_active` | 有効な目標のみの取得 |

## Dexie スキーマ例

```ts
db.version(1).stores({
  goals: '++id, period, category_id, is_active',
});
```

## TypeScript 型定義

```ts
export interface Goal {
  id?: number;
  target_minutes: number;
  period: 'daily' | 'weekly' | 'monthly';
  category_id?: number | null;
  is_active: boolean;
  created_at: number;
  updated_at: number;
}
```
