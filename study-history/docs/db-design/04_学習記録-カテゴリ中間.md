# 学習記録-カテゴリ中間（`study_record_categories`）

学習記録とカテゴリの多対多関連を表す中間テーブル。

## カラム

| カラム名 | 型 | NULL | 既定値 | 説明 |
|---|---|---|---|---|
| `id` | number (auto-increment) | NO | 自動 | 主キー |
| `study_record_id` | number | NO | — | `study_records.id` への参照 |
| `category_id` | number | NO | — | `categories.id` への参照 |
| `created_at` | number (epoch ms) | NO | 自動 | レコード作成時刻 |

## インデックス

| 名称 | カラム | 用途 |
|---|---|---|
| `idx_study_record_id` | `study_record_id` | 記録から紐づくカテゴリ取得 |
| `idx_category_id` | `category_id` | カテゴリから紐づく記録取得（カテゴリ別集計） |
| `idx_unique_pair` | `[study_record_id+category_id]` (unique) | 同一ペア重複防止 |

## Dexie スキーマ例

```ts
db.version(1).stores({
  study_record_categories: '++id, study_record_id, category_id, &[study_record_id+category_id]',
});
```

## TypeScript 型定義

```ts
export interface StudyRecordCategory {
  id?: number;
  study_record_id: number;
  category_id: number;
  created_at: number;
}
```
