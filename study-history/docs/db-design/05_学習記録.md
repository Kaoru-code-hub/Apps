# 学習記録（`study_records`）

タイマーを終了するたびに 1 件作成される、学習セッションの記録。

## カラム

| カラム名 | 型 | NULL | 既定値 | 説明 |
|---|---|---|---|---|
| `id` | number (auto-increment) | NO | 自動 | 主キー |
| `started_at` | number (epoch ms) | NO | — | 計測開始時刻（UNIX epoch ミリ秒） |
| `ended_at` | number (epoch ms) | NO | — | 計測終了時刻（UNIX epoch ミリ秒） |
| `duration_seconds` | number | NO | — | 実学習時間（秒）。休憩時間は含まない |
| `duration_minutes` | number | NO | — | 実学習時間（分）。`duration_seconds / 60` の切り捨て。集計用 |
| `break_seconds` | number | NO | 0 | 休憩合計時間（秒）。参考情報として保持 |
| `break_minutes` | number | NO | 0 | 休憩合計時間（分）。`break_seconds / 60` の切り捨て。集計用 |
| `material_name` | string | YES | null | 教材名（任意） |
| `achievement` | number (1-5) | YES | null | 達成度（暫定：5 段階）※要件未確定 |
| `memo` | string | YES | null | 自由記述メモ（将来拡張用、Phase 1 では UI 提供しなくてもよい） |
| `created_at` | number (epoch ms) | NO | 自動 | レコード作成時刻 |
| `updated_at` | number (epoch ms) | NO | 自動 | レコード最終更新時刻 |

## インデックス

| 名称 | カラム | 用途 |
|---|---|---|
| `idx_started_at` | `started_at` | 日次／週次／月次の集計、期間絞り込み |
| `idx_ended_at` | `ended_at` | 補助。期間境界をまたぐ記録の検索用 |

## Dexie スキーマ例

```ts
db.version(2).stores({
  study_records: '++id, started_at, ended_at',
});
```

## TypeScript 型定義

```ts
export interface StudyRecord {
  id?: number;
  started_at: number;
  ended_at: number;
  duration_seconds: number;
  duration_minutes: number;
  break_seconds: number;
  break_minutes: number;
  material_name?: string | null;
  achievement?: number | null;
  memo?: string | null;
  created_at: number;
  updated_at: number;
}
```
