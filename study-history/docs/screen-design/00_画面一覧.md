# 画面一覧

| 画面ID | 画面名 | 概要 | 主要操作 |
|--------|--------|------|---------|
| SCR-01 | スタート画面（ホーム） | アプリ起動時のトップ。計測開始と各機能への入口 | 「勉強をスタート」／メニュー遷移 |
| SCR-02 | 計測準備画面 | 計測開始前にカテゴリ・教材名を入力 | カテゴリ選択（複数可） / 教材名入力 / 計測開始 / キャンセル |
| SCR-03 | 計測画面 | ストップウォッチ表示。学習時間を計測する | 休憩 / 再開 / 計測終了 |
| SCR-04 | 計測終了・記録確認画面 | 計測結果の確認と達成度を入力後に保存 | 達成度入力 / 保存 / 破棄 |
| SCR-05 | 学習記録一覧画面 | 過去の学習記録の一覧表示 | 記録の選択 / 編集 / 削除 |
| SCR-06 | 学習記録 編集画面 | 既存の学習記録を編集 | 編集 / 保存 / キャンセル |
| SCR-07 | ダッシュボード画面 | 統計・グラフを表示 | 期間切替（日/週/月） / カテゴリ別切替 |
| SCR-08 | カテゴリ管理画面 | カテゴリの一覧・作成・編集・削除 | カテゴリ追加 / 編集 / 削除 |
| SCR-09 | 目標設定画面 | 目標時間（日/週/月、全体/カテゴリ別）の設定 | 目標追加 / 編集 / 有効・無効切替 / 削除 |
| SCR-10 | 離脱警告ダイアログ | 計測中にタブ／アプリを閉じようとした際の警告 | キャンセル / そのまま離脱 |
